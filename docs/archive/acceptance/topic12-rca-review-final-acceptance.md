# 专题 12：RCA 审核最终验收

验收日期：2026-08-04

## 最终结论

专题 12 已达到实习生项目最终汇报程度。四 Agent 深度 RCA 从事实快照、程序校验、人工草稿、确认/修正/驳回，到可选知识发布形成可追溯闭环；审核版本不可省略，并发覆盖与重复提交返回 HTTP 409。

## 正式业务口径

- 审核工作台只承接 `DEEP` RCA；快速 RCA 保留在 Incident/告警详情作为定位线索。
- 低于 0.70 的结果明确标记必须人工复核；事实、部分支持与假设分级展示。
- `CONFIRM` 采用 Agent 结论；`MODIFY` 必须填写修正说明；`REJECT` 必须填写驳回原因。
- 驳回结论禁止发布知识；确认或修正只有在审核人主动勾选时才发布 `AGENT_RCA` 知识。
- 草稿和最终审核都必须携带 `expectedVersion`；过期版本、重复审核或已结束状态返回 HTTP 409。
- 草稿保存和最终结论均写入不可变系统审计，记录版本变化、结论和知识发布选择。
- 已完成审核的详情展示最终状态、审核人、审核时间、审核说明和知识沉淀结果。
