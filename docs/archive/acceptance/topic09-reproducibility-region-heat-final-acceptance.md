## 可重现性

- 有效枚举统一为 `ALWAYS/FREQUENT/OCCASIONAL/ONCE`，页面展示为必现、频繁、偶发、一次。
- 数据库 `NULL` 和空字符串统一归入 `UNKNOWN`，不再出现空白饼图区块或漏计。
- 图表只展示有效枚举；下方同时展示字段完整率和缺失数。
- 点击有效扇区进入相同时间、渠道、模块、类型、严重度、状态和权限口径的反馈明细。
- 点击缺失数进入 `UNKNOWN` 明细，能够追溯并推动数据补齐。

### 量化判定标准（reproducibility-v1）

复现率计算公式为：`成功复现次数 / 同条件有效尝试次数 × 100%`。同条件至少包括应用版本、设备型号、操作系统、网络、账号/数据状态和操作步骤一致。比例分类要求至少 3 次有效尝试：

| 类别 | 量化规则 |
|---|---|
| 必现 | 有效尝试不少于 3 次，复现率 ≥ 90%；在最低 3 次样本下即 3/3 均成功 |
| 频繁 | 有效尝试不少于 3 次，50% ≤ 复现率 < 90%；在最低 3 次样本下通常为 2/3 |
| 偶发 | 有效尝试不少于 3 次，0 < 复现率 < 50%；在最低 3 次样本下通常为 1/3 |
| 一次 | 仅观察到 1 次，且尚无不少于 3 次的同条件有效尝试，不把 1/1 表述成 100% 必现 |
| 未知 | 尝试次数、成功次数或同条件证据缺失，或者多次尝试均未复现 |

当前表结构只保存分类结果，没有保存复现尝试次数与成功次数，因此系统暂不自动推算类别；来源明确提供标签时进行枚举归一化，否则归为未知。最终汇报不得将来源标签描述为平台自动化实验结论。后续如建设自动判定，应新增受控复现实验记录，并保留环境快照、尝试次数、成功次数、判定版本和判定人。

## 地区热度

- 全国层级严格按省份聚合，同一省份不再因城市不同重复出现。
- 点击省份进入该省城市排名，点击城市进入该省、该城市的反馈明细。
- 省份和城市的 `NULL`、空字符串统一按缺失处理，不参与有效热度排名。
- 页面按当前层级展示省份或城市字段完整率，缺失记录可下钻追溯。
- 保留地区数据权限约束；无有效地区时展示真实空状态，不使用未知地区伪造排名。
