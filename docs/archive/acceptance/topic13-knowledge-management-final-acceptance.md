# 专题 13：知识库管理最终验收

## 结论

截至 2026-08-04，专题 13 已达到实习生项目最终汇报所需的正式闭环程度。知识条目的来源、版本、有效期、检索资格和审计追溯均形成了可执行规则，并通过真实 MySQL、JWT 与 HTTP 链路验证。

本结论针对课程项目和汇报验收，不等同于生产上线批准。

## 闭环范围

| 维度 | 闭环规则 | 验收结果 |
| --- | --- | --- |
| 来源 | 保留 `MANUAL` 与 `AGENT_RCA` 来源；RCA 条目携带 `sourceRcaId` | 管理列表、详情与检索结果均返回来源和 RCA 引用 |
| 版本 | 原记录不可覆盖；已发布条目编辑时创建待审核修订，并以 `supersedesId` 串联 | 新版发布后，前序发布版在同一事务内转为 `DEPRECATED` |
| 并发 | 编辑、审核、废弃均要求 `expectedVersion` | 缺失版本返回 400；陈旧版本返回 HTTP 409 |
| 过期 | 新增 `expires_at`；不额外污染五态生命周期模型 | `PUBLISHED` 且过期的条目显示为 `EXPIRED`，保留历史但不再检索 |
| 检索 | 仅检索已发布且未过期条目 | 查询条件固定为 `PUBLISHED AND (expires_at IS NULL OR expires_at > NOW())` |
| 追溯 | 检索返回知识来源、RCA、前序版本、生命周期版本、发布/过期时间 | 每个结果携带 `KNOWLEDGE:<id>` 追溯标识和匹配原因 |
| 废弃 | “归档”改为“停止推荐/废弃”，避免误解为删除 | 历史行和审计保留，推荐资格立即取消 |
| 审计 | 创建、编辑、修订、发布、替代、驳回和废弃均写业务审计 | 真实链路验证关键操作审计齐全 |

## 页面口径

- 列表中的生命周期状态仍为 `DRAFT / PENDING_REVIEW / PUBLISHED / REJECTED / DEPRECATED`。
- 在线可用状态单独展示：已发布且未过期为“在线可检索”，已发布但超过有效期为“已过期，不再推荐”。
- 详情展示来源、RCA 编号、追溯标识、生命周期版本、前序/后续版本、发布时间和有效期。
- 已发布内容的编辑不会直接修改线上版本，而是生成新的待审核修订。
