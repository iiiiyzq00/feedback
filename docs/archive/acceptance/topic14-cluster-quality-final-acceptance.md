# 专题 14：归簇质量最终验收

## 最终结论

截至 2026-08-04，专题 14 已达到实习生项目最终汇报所需的闭环程度。归簇质量验收不再只输出 PASS/FAIL，而是基于固定标注集、簇级金标准、人工抽检和六项门禁指标，形成“保留 / 补齐 / 重构 / 合并”四类可执行结论。

本结论面向课程项目验收，不代表生产流量下的算法发布批准。

## 对当前方案的正式判断

| 结论 | 当前判断 | 依据与动作 |
| --- | --- | --- |
| 保留 | 保留现有归簇主链 | 硬边界、候选匹配、人工审核、合并拆分血缘、乐观锁和审计机制已经具备；完整标注集通过门禁时继续保留该算法版本 |
| 补齐 | 本专题已完成 | 补齐簇数量、平均簇大小、孤立簇比例、相似度分布、簇纯度、错误拆分率、未归簇率、单簇异常样本和人工好/坏簇标注 |
| 重构 | 条件触发 | 混入多个金标准诉求、纯度不足、错误合并超限、人工标为坏簇或其他核心指标失败时，不允许发布，应重构画像、硬边界或候选打分策略 |
| 合并 | 条件触发 | 同一金标准诉求被拆成多个预测簇且簇内纯度合格时，判定为过度拆分，建议合并簇或收敛拆分阈值 |

因此，当前系统不是“全部重构”或“盲目保留”，而是保留已经闭环的治理主链，并由每次独立评估对具体算法版本给出处置结论。

## 正式门禁

一份评估必须满足：

- 100～5000 条脱敏样本；
- SDK、Jira、质量平台、红黑榜四渠道均覆盖，且每渠道至少 10 条；
- 不得使用联系方式、身份或设备指纹作为归簇依据；
- 提供预测簇 ID、金标准簇 ID；
- 对每个预测簇提供独立人工 `GOOD/BAD` 结论和理由；
- F1 ≥ 0.75；
- 错误合并率 ≤ 0.05；
- 人工推翻率 ≤ 0.15；
- 簇纯度 ≥ 0.80；
- 错误拆分率 ≤ 0.15；
- 未归簇率 ≤ 0.15；
- 所有人工簇结论均为 GOOD。

只有上述条件同时满足，门禁才输出 PASS 和“保留”。仅有成对判断数据时固定 FAIL，并输出“补齐”。

## 四类判定规则

| 系统代码 | 中文结论 | 判定条件 |
| --- | --- | --- |
| `KEEP` | 保留 | 证据完整且所有正式门禁通过 |
| `COMPLETE` | 补齐 | 缺预测/金标准簇或人工簇标注覆盖不完整 |
| `MERGE` | 合并 | 主要问题是同一金标准被过度拆分，且错误合并率、簇纯度仍合格 |
| `REFACTOR` | 重构 | 混簇、人工判坏或其他核心质量门禁失败 |
