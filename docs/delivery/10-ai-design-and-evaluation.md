# 交付物 10：AI 功能设计与效果评估

## 1. 能力与降级

| 能力 | 输入 | 输出 | 降级 |
|---|---|---|---|
| 自动分类摘要 | PASS 标题、正文和批准字段 | 应用、模块、类型、情绪、严重度、风险、摘要、团队、置信度、来源 | 确定性规则 |
| 相似问题 | 脱敏文本、应用、模块、版本、时间、错误签名 | 候选、相似度、证据和决策类型 | 文本候选或保守新建簇 |
| 分析助手 | 程序查询事实和问题 | 带时间、来源、口径和事实/推断标识的回答 | 直接返回结构化事实 |
| 报告叙述 | 后端计算事实 | 文字总结 | SQL 事实模板 |
| RCA | 问题簇、版本、告警和历史事实 | 根因候选、证据、置信度 | 规则/模板与人工审核 |

AI 通过可替换 `LlmClient` 接入。Prompt 文件、模型参数和 SHA-256 登记在 `prompts/manifest.json`；发布遵循草稿、结构测试、标注集评估、双人审批、发布/回滚。输出必须是受校验的结构化 JSON，未知分类失败关闭。

## 2. 输出治理

分类输出包含应用、模块、类型、情绪、严重度、风险、摘要、团队、置信度和数据来源。统计数字由程序查询生成，模型只叙述事实。低置信度和 S0/S1 进入人工复核。

模型不能直接覆盖来源字段、统计数字或正式问题簇。JSON 先经过结构、枚举、长度、置信度和隐私校验；人工结论优先于 AI，并保留原 AI 快照。

## 3. 成本与运行治理

每次调用保存 Prompt/Skill/模型版本、token、延迟、估算费用和供应商请求号。日 token 配额、超时、重试、熔断和自动回滚控制成本与故障；不可用时分类回退确定性规则，报告/助手回退 SQL 事实和模板文字。

输入/输出百万 token 单价和每日 token 配额均可配置。配额为 0 表示未启用额度限制，不代表调用免费。成本、失败率和回滚状态可按 Skill、Prompt 和模型版本统计。

## 4. 分类效果评估

评估集覆盖七类问题、S0–S4、四渠道切片、边界表达、注入和隐私安全，计算整体准确率、S1 召回率和安全通过率。人工复核治理阈值经 2026-08-07 标注集校准：当前模型（deepseek-v4-pro）稳定准确率 74.6%（多数表决），验收线定为 **0.74**；**0.85 保留为模型升级后的目标阈值**，不宣称是未经校准的最优阈值。

## 5. 归簇效果评估

四渠道标注集至少 100 条，计算 Precision、Recall、F1、错误合并率、人工推翻率、簇纯度、错误拆分率和未归簇率。评估以影子方式运行，不直接修改正式关联；失败结论给出补齐、重构或合并建议。

效果评估见 `../archive/acceptance/topic01-ai-classification-final-acceptance.md`、`../archive/acceptance/topic14-cluster-quality-final-acceptance.md`、`../../prompts/README.md` 和 `../../../docs/verification/verification-ai-system.md`。

## 6. 安全控制

AI 任务创建、执行前和输出落库前均检查隐私状态。输入只从批准字段白名单组装并再次扫描；Prompt 注入内容按不可信数据处理，不能改变系统指令、权限或查询范围。模型输出经过 JSON Schema、枚举、长度、敏感信息恢复和证据引用校验，不合格结果进入失败或复核状态。

模型不能自行查询任意 SQL、计算报表数字、读取隔离区、解密附件或扩大用户的数据范围。分析助手先解析受支持意图，再以当前用户权限执行参数化查询，最后把已计算事实交给模型叙述。

## 7. 发布门槛与结果记录

| 评估项 | 发布判断 |
|---|---|
| 分类结构有效率 | 达到配置阈值；越界枚举失败关闭 |
| S0/S1 召回 | 单独统计，不能被总体准确率掩盖 |
| 隐私/注入安全 | 高风险样例不得绕过，失败即阻断发布 |
| 归簇错误合并率 | 超阈值只运行影子候选 |
| 成本与延迟 | 记录 P50/P95、token 与估算费用 |
| 降级 | 关闭模型后接入、查询、统计继续通过 |

每次评估报告注明代码、数据集、样本量、渠道切片、阈值、混淆矩阵、失败案例、人工复核和发布决定。没有可复现报告时不得声称达到生产准确率。
