# Agent 上下文与 Token 成本治理

## 目标

在不削弱安全、事实边界和验证质量的前提下，减少重复读取、长日志、失败方案和旧历史造成的输入 Token。Prompt Cache 是成本优化手段，不是保留无限上下文的理由。

## 稳定前缀

- `AGENTS.md` 只放长期仓库规则、固定目录边界和验证要求，避免加入日期、当前版本、临时待办或部署状态。
- 新任务默认只加载 `PROJECT_SNAPSHOT.md`。完整 `PROJECT_MEMORY.md` 和专题文档按任务路由读取。
- 保持模型、供应商、reasoning effort、工作目录、插件和工具配置稳定；确需切换时记录原因，不在同一任务中来回切换。
- 相同事实只在一个位置维护，其他文件使用链接，避免多份长文本同时进入上下文。

## 读取预算

- 开局：`AGENTS.md`、短快照和 `tools/context-start.sh` 的低输出摘要；只对任务涉及路径展开精确状态。
- 探索：先 `rg` 定位，再读最小相关行段；不要扫描 archive、构建输出、缓存或整个源码树。
- 当前任务默认只读一个交付/专题入口；第二个入口必须与待决问题直接相关。
- 命令输出超过约 200 行时改为摘要、过滤或保存证据文件；对话只保留结论和关键错误片段。

## 浏览器交互禁令

- 本仓库默认禁止 Agent 打开、接管或自动操作任何浏览器，包括应用内浏览器、Chrome/Edge、Playwright、截图、登录、OAuth 授权、点击、输入和页面目视验收。
- 不得为了排查、复现或验证而预先加载浏览器控制技能说明；完整浏览器说明和连续页面快照会显著扩大后续每次调用的缓存 Token。
- 当任务必须进行页面交互时，立即停止自动执行，向用户提供准确 URL、最多五步的最小操作步骤和需要回传的结果；用户完成操作并回复后，再基于其结果继续。
- 只有用户在当前轮明确覆盖本禁令，且 Agent 已先说明预期 Token 成本时，才允许为该轮使用浏览器工具。该授权一次有效，不跨轮次、不跨任务继承。
- 自动化验证优先使用单元测试、集成测试、HTTP/API、结构化日志和数据库只读事实；不得为了得到同一结论再追加浏览器验证。

## 成本审计

从应用根运行 `../tools/audit-ai-cost.sh 1 --report` 查看最近一天的 Token、缓存、长上下文、压缩、按会话归因和供应商分布；使用 `--json` 生成机器可读结果。`--enforce` 会在超过 `config/codex-cost-policy.json` 阈值时返回非零，适合本地治理或独立定时任务，不接入共享 CI，因为 CI 通常无权读取个人 Codex 会话。

成本策略默认要求缓存命中率不低于93%、超过100k的调用不高于15%、超过200k的调用不高于2%。这些是优化目标，不是生产功能门禁。自定义供应商价格未核验前，只报告 Token，不估算货币成本。

## 强制压缩触发器

满足任一条件就先压缩，再进入下一阶段：

- 累计约 12 次工具调用；
- 同一问题已经尝试两种失败方案；
- 从后端切换到前端、部署或真实环境验证；
- 输入上下文接近 60k token；
- 输入上下文接近100k token时生成交接并停止继续扩展原会话；
- 任务跨天、交接或准备开启新会话；
- 日志、diff 或工具输出开始重复出现。

## 标准压缩 Prompt

```text
请整理当前任务上下文，删除重复日志、已否决方案、已解决的中间错误、
无关历史和冗长工具输出。不要重新叙述完整项目背景。

只保留：
1. 当前目标，以及明确不在范围内的事项；
2. 已确认的关键事实和决策；
3. 必须遵守的项目、安全和数据约束；
4. 当前分支、工作区状态，以及必须保留的既有改动；
5. 已修改文件及每个修改的目的；
6. 已完成验证及结论，不复制完整日志；
7. 未解决问题、阻塞条件和待核验事实；
8. 接下来最多三个具体行动。

不确定事实标记“待核验”。本机、Mock、降级或静态测试不得写成生产集成成功。
输出一份可直接作为后续执行起点的简洁摘要。后续只基于该摘要、
AGENTS.md、PROJECT_SNAPSHOT.md 和下一步必需文件继续，不重载已解决历史。
```

## 收尾格式

```text
完成：实现和最小可复现证据
未完成：具体差距及关闭条件
工作区：相关文件与需要保留的无关改动
待核验：尚不能确认的事实
下一步：最多 3 项
```

完整命令、计数、截图和长输出进入对应证据文件；项目快照只保存当前结论和入口。

## 可复用技能

- `compact-project-context`：生成最小可执行交接，并可运行只读 Token 元数据审计。
- `guard-flyway-change`：处理迁移、checksum、回填和数据库验证。
- `verify-delivery-claim`：校准 Mock、本机、目标环境和生产结论。

技能位于 `../../../../../feedback-platform.backup-20260905/.agents/skills/`。从上级工作目录启动的 Agent 如果未自动发现技能，应按 `AGENTS.md` 的路由直接读取对应 `SKILL.md`；不要把三个技能同时加载到无关任务中。
