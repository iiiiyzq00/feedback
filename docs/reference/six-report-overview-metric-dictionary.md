# 六类 AI 报告概览指标字典

指标版本：`six-report-overview-v1`。生效范围：新生成的六类 AI 报告；历史报告保留生成时快照，不回写历史数据。

## 共通门禁

所有反馈类指标均只统计当前报告权限快照内、未删除、脱敏状态为 `PASS`，且 `COALESCE(source_event_time, ingest_time)` 位于报告周期内的不同 `t_feedback_source.id`。主问题簇只统计 `t_cluster_link.is_active=1 AND relation_role='MAIN'` 的不同 `cluster_id`；未归簇反馈指没有上述 MAIN 关系的主题反馈。

| 报告类型 | 主指标（兼容字段 `rawRecordCount`） | 次指标（兼容字段 `uniqueProblemCount`） | 报告主题附加条件 |
|---|---|---|---|
| 每日数据接入 | 有效反馈（条） | 主问题簇（个） | 无；周期默认为前一日 |
| 每周多渠道趋势 | 有效反馈（条） | 主问题簇（个） | 无；周期默认为上一完整自然周 |
| 版本上线观察 | 版本反馈（条） | 版本主问题簇（个） | 指定 `packageName + version` |
| 质量关联 | 质量样本（条） | 质量主问题簇（个） | `source_channel='QUALITY'` |
| 红黑榜分析 | 红黑榜样本（条） | 红黑榜主问题簇（个） | `source_channel='REDBLACK'` |
| 风险与舆情简报 | 风险分析反馈（条） | 风险主问题簇（个） | 当前风险计算的数据权限和报告周期范围 |

## API 与快照

事实快照的 `overviewMetrics` 固化指标版本、主题、权限/周期过滤条件、指标代码、名称、单位、数值和定义。列表 API 同时返回该对象。数据库列名继续保留，以免破坏既有客户端，但展示层必须使用快照中的中文指标名称，不得再把 `uniqueProblemCount` 解释为“反馈去重后的记录数”。

若报告账号不具备主题渠道权限，例如仅有 SDK 权限却生成质量关联报告，则质量样本和质量主问题簇均应为 0；不得用 SDK 总量填充。
